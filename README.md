# Binary Logistic Regression with Adam

## Overview

This Python coursework project implemented a binary logistic-regression workflow for classifying mushroom observations. It covered data preparation, likelihood-based modelling, mini-batch gradient calculations, optimisation with a custom Adam implementation, and model evaluation.

## Technical focus

- Numerical data processing with NumPy and pandas
- Binary logistic regression and log-likelihood evaluation
- Mini-batch gradient computation
- Adam optimisation implemented from first principles
- Prediction generation and accuracy measurement
